# lucky-primrose-lite

PostgreSQL · TypeScript · React

学习用的示例项目

## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/lucky-primrose-lite.git
cd lucky-primrose-lite
pip install -r requirements.txt
```
